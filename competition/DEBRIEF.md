# Individual explanation rehearsal

These prompts are practice, not proof the owner has mastered the code.

1. Trace schedule JSON through the CLI, graph validation and critical path.
2. Explain why 30 minutes critical path can coexist with 40 minutes total work.
3. Show a missing dependency and a cycle; explain their different causes.
4. Why must baseline and candidate use identical case IDs?
5. Reproduce the finite-input overflow regression and explain scaling before summation.
6. Change a journal byte. What is detected? What could a full rewrite conceal?
7. Explain why a hash does not authenticate the event or owner.
8. Show what happens when Node is absent: dashboard tests skip, not pass.
9. Explain why a static dashboard is not the official service entrypoint.
10. Identify one actual limitation and the smallest testable next improvement.

For the real debrief, use the official submitted commit and organizer results.
Never claim synthetic fixtures are hidden tests or user studies.
