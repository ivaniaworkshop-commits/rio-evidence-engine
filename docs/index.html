One program. Explicit authority.

One API and CLI manage parser routing, declared-count checks, all three checkpoint versions, verified loading and in-memory reuse. API and CLI outputs matched. EXTERNAL VALIDATION INSTRUMENT

Ready to be run by an external evaluator.

Standalone standard-library grader; exact-commit clean Git checkouts; separate Python worker processes; expected labels omitted from worker messages; independent parent graph comparator; exact disclosed-text overlap rejection. Reports are aggregate-only, exclusively created with permissions 0600.

Previous strict suite: 214 passed, zero skipped, including 11 authored instrument tests. These fixtures validate the tool, not external model capability.
