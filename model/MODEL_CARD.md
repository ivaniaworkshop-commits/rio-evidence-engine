# Small trained byte language model

Status: trained locally, checkpoint saved and reloaded, inference observed.
Architecture: 256-byte vocabulary, 16-dimensional embedding, single GRU with
32 hidden units, linear byte prediction head. 17,344 learned parameters.
This is a SMALL neural language model, not a transformer or an LLM.

## Run

The Python evidence engine still has no required third-party dependencies.
Neural commands additionally require the optional CPU runtime:

```sh
python -m pip install -r model/requirements-cpu.txt
python -m rio_evidence.neural_lm generate --prompt 'Case: parallel' --max-bytes 64
python -m rio_evidence.neural_lm train --steps 250
```

Training overwrites model/byte_gru.pt and model/TRAINING_RESULT.json. Only run
it intentionally. Checkpoint loading uses weights_only=True; load only trusted
project checkpoints. No private Río data was used. Corpus consists of the
public 128 authored scenarios, divided into 102 practice and 26 evaluation cases.
The split shares templates and is publicly available; loss is not evidence of
independent generalization or numerical task accuracy. Greedy text generation
is presently repetitive and unreliable. Do not use generated numbers as answers.

## Hybrid task interface

`python -m rio_evidence.hybrid examples/schedule.json --neural` calculates the
schedule in deterministic code and uses this model only to rank three grounded
English templates by average byte log likelihood. The numerical answer is never
generated by the model. Without torch/checkpoint or when ranking fails, it uses
a deterministic template; invalid task graphs still fail.

HYBRID_EVALUATION.json compares 26 existing reference cases plus 16 new authored
DAGs against an exhaustive path oracle. This is system evaluation, not improved
neural arithmetic. Ranking preference has no independent quality validation;
correctness would also be available without the neural component. The earlier
0/26 free-generation probe remains unchanged.

Free generation now rejects prompt-plus-requested-continuation budgets above
128 UTF-8 bytes. No prompt suffix slicing or sliding window is used on accepted
requests. Default output is 64 bytes. This conservative contract preserves all
input bytes; it does not prove the model retains them semantically. Rejection
happens before runtime/model load and is reported by CLI with exit code 2.
Current 28-case extraction evaluation is blocked at this boundary, not counted
as semantic abstention or inference. Earlier failed generation is historical.
The trained checkpoint is unchanged. Longer-context architecture/evaluation is
a separate delta; no context extension or retraining occurred.
